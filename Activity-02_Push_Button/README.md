# Activity 02 – Push Button

## 1. Objective

To understand digital input programming using Arduino by reading the state of a push button and controlling an LED based on the button input.

## 2. Components Used

* Arduino UNO
* Push Button
* LED
* 220 Ω Resistor
* Breadboard
* Jumper Wires

## 3. Circuit Diagram

The circuit was designed and simulated using Tinkercad.

![Circuit Diagram](circuit.png)

## 4. Arduino Program

The Arduino program is available in the `code.ino` file.

## 5. Output

When the push button is pressed, the LED turns ON. When the push button is released, the LED turns OFF.

## 6. Learning Outcome

* Understood digital input pins.
* Learned the use of `pinMode()`.
* Learned the use of `digitalRead()`.
* Learned how to read the state of a push button.
* Learned how to control an LED based on user input.

## 7. Challenges Faced

* Initially checked the push button and LED connections.
* Verified the Arduino pin numbers used in the program.
* Checked the resistor connection for the LED.
* Corrected any syntax errors in the Arduino code.
* Verified the button input and LED output in Tinkercad.

## 8. Real-World Applications

* Emergency stop buttons
* Doorbell systems
* Control panels
* Security systems
* Device ON/OFF controls
