# Activity 01 – LED Blink

## 1. Objective

To understand digital output programming using Arduino by blinking an LED.

## 2. Components Used

- Arduino UNO
- LED
- 220 Ω Resistor
- Breadboard
- Jumper Wires

## 3. Circuit Diagram

The circuit was designed and simulated using Tinkercad.

![Circuit Diagram](circuit.png)

## 4. Arduino Program

The Arduino program is available in the `code.ino` file.

## 5. Output

The LED blinks continuously with a 1-second delay between ON and OFF states.

## 6. Learning Outcome

- Understood digital output pins.
- Learned the use of `pinMode()`.
- Learned the use of `digitalWrite()`.
- Understood the use of `delay()`.

## 7. Challenges Faced

- Initially checked the LED connection and resistor connection.
- Verified the Arduino pin number used in the program.
- Corrected any syntax errors in the Arduino code.

## 8. Real-World Applications

- Status indicators
- Warning systems
- Traffic signal controllers
