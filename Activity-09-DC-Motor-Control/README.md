Activity 09 – DC Motor Control
1. Objective

To understand motor control using Arduino by controlling the ON and OFF operation of a DC motor using a motor driver.

2. Components Used
Arduino UNO
DC Motor
L293D Motor Driver IC
Breadboard
Jumper Wires
External Battery Supply
3. Circuit Diagram

The circuit was designed and simulated using Tinkercad.

4. Arduino Program

The Arduino program is available in the code.ino file.

5. Output

The Arduino controls the DC motor through the L293D motor driver. The motor turns ON and rotates when the control signal is given and turns OFF when the signal is removed.

6. Learning Outcome
Understood the basic working of a DC motor.
Learned how to interface a DC motor with Arduino.
Understood the purpose of a motor driver.
Learned how to control a motor using digital output pins.
Learned the use of digitalWrite().
Understood why a motor should not be directly connected to an Arduino pin.
7. Challenges Faced
Initially checked the motor and L293D connections.
Verified the Arduino control pin connections.
Checked the motor power supply.
Verified the correct motor driver pin connections.
Tested the motor ON and OFF conditions in Tinkercad.
Corrected any syntax errors in the Arduino code.
