Activity 11 – LCD Display
1. Objective

To understand LCD interfacing with Arduino by displaying text and sensor values on a 16×2 LCD display.

2. Components Used
Arduino UNO
16×2 LCD Display
10 kΩ Potentiometer
Breadboard
Jumper Wires
3. Circuit Diagram

The circuit was designed and simulated using Tinkercad.

4. Arduino Program

The Arduino program is available in the code.ino file.

5. Output

The LCD displays a message such as "Hello World!" and demonstrates how Arduino can send and display information on the LCD screen.

6. Learning Outcome
Understood the working principle of a 16×2 LCD.
Learned how to interface an LCD with Arduino.
Learned the use of the LiquidCrystal library.
Learned how to display text on an LCD.
Understood how LCDs can be used to display sensor readings and system information.
7. Challenges Faced
Initially checked the LCD power and ground connections.
Verified the LCD RS, EN, and data pin connections.
Adjusted the LCD contrast using the potentiometer.
Verified the correct Arduino pin numbers in the program.
Checked the displayed text in Tinkercad.
Corrected any syntax errors in the Arduino code.
8. Real-World Applications
Digital meters
Temperature monitoring systems
Sensor monitoring
Industrial control panels
Electronic devices
User interface systems
