Activity 10 – Seven Segment Display
1. Objective

To understand digital output programming using Arduino by displaying numbers from 0 to 9 on a seven segment display.

2. Components Used
Arduino UNO
7-Segment Display
7 × 220 Ω Resistors
Breadboard
Jumper Wires
3. Circuit Diagram

The circuit was designed and simulated using Tinkercad.

4. Arduino Program

The Arduino program is available in the code.ino file.

5. Output

The seven segment display displays the numbers 0 to 9 sequentially. Each number is displayed for one second before changing to the next number.

6. Learning Outcome
Understood the working principle of a seven segment display.
Learned how to interface a seven segment display with Arduino.
Learned how to control individual segments using digital output pins.
Learned the use of digitalWrite().
Understood how numbers are represented using different LED segments.
7. Challenges Faced
Initially checked the seven segment display connections.
Verified the correct Arduino pin numbers.
Checked the resistor connections for each segment.
Verified the common pin connection of the display.
Tested the number sequence in Tinkercad.
Corrected any syntax errors in the Arduino code.
