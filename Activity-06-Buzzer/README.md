# Activity 06 – Buzzer

## 1. Objective

To understand digital output programming using Arduino by controlling a buzzer to produce an audible sound.

## 2. Components Used

* Arduino UNO
* Buzzer
* Breadboard
* Jumper Wires

## 3. Circuit Diagram

The circuit was designed and simulated using Tinkercad.

![Circuit Diagram](circuit.png)

## 4. Arduino Program

The Arduino program is available in the `code.ino` file.

## 5. Output

The buzzer produces a sound when it is turned ON and stops when it is turned OFF. The buzzer is controlled using an Arduino digital output pin.

## 6. Learning Outcome

* Understood digital output control using Arduino.
* Learned the use of `pinMode()`.
* Learned the use of `digitalWrite()`.
* Understood how to control a buzzer using Arduino.
* Learned how electronic components can be controlled through digital output pins.

## 7. Challenges Faced

* Initially checked the buzzer VCC and GND connections.
* Verified the correct Arduino pin number.
* Checked the buzzer operation in Tinkercad.
* Verified the ON and OFF conditions.
* Corrected any syntax errors in the Arduino code.
